# Efficient Intelligence Group

Academic research-group website for the Efficient Intelligence Group at Leiden University.

## Content

Most structured content is maintained in `lib/site-data.ts`, including research areas, people, publications, news, and student projects. Images live in `public/images`.

## Local development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Validation

```bash
pnpm build
```

Source repository: [qinche106/efficient-intelligence-group](https://github.com/qinche106/efficient-intelligence-group).

The current production preview is deployed separately. Configure the final hosting target and custom domain only after the content review is complete.

## Content provenance

The initial text and photography were migrated from the group’s existing public Google Sites website. Review member details, publication metadata, current vacancies, and image permissions before the final domain switch.
